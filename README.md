# SmartBudget

SmartBudget is a full-stack budget management web application that helps users track their income, expenses, and monthly budget.

## Features

- User authentication (Login/Register)
- Add and view transactions
- Set a monthly budget
- Dashboard overview of income, expenses, and remaining balance

## Tech Stack

- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB
- Styling: CSS, Tailwind CSS (optional)
